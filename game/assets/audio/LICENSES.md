# 音频素材许可

本目录音频分三类：

## 1. CC0 外部采样（可商用、免署名）

| 用途 | 来源 | 许可 |
|---|---|---|
| 脚步 ×3、挥砍、命中、开门、建造、金币 | [Kenney RPG Audio](https://kenney.nl/assets/rpg-audio)（镜像：[Boyquotes/kenney-rpg-audio-for-godot](https://github.com/Boyquotes/kenney-rpg-audio-for-godot)） | CC0 1.0 |
| UI 点击 | [Kenney UI Audio](https://kenney.nl/assets/ui-audio)（镜像：[Calinou/kenney-ui-audio](https://github.com/Calinou/kenney-ui-audio)） | CC0 1.0 |
| 死亡、Boss 吼 | [RPG Sound Pack](https://opengameart.org/content/rpg-sound-pack) by artisticdude | CC0 1.0 |

CC0 1.0 法律文本见同目录 `CC0-1.0.txt`。

## 2. 本项目程序合成（Apache-2.0）

爆炸、电流、蒸汽、UI 错误、胜利/失败、30s 环境 loop 由 `game/tools/audio/gen_sfx.py`（numpy）生成，随本仓库 Apache-2.0 发布。

## 3. 替换说明

早期程序合成的脚步/挥砍/命中/开门/建造/金币/UI 点击/Boss/死亡已被上述 CC0 采样替换；生成脚本仍保留，用于缺失音效与环境 loop 的兜底。
