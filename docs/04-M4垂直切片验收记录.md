# 04 · M4 垂直切片验收记录

> 日期：2026-10-30 · 对应 tag `m4`、`m5` · 环境：Godot 4.7.2 headless

## 验收方式

自动化脚本驱动 `RunController`（`tests/scenarios/m4_vertical_slice.gd`），复现 `docs/01 §2.1` 的 1–7 步：
开局 → 探索/清房 → 获得蓝图 → 构筑节点放置房间 → 进入新房间 → 战斗/事件/休整/商店 → Boss → 结算。

## 结果（种子 20261030，单层）

```json
{
  "floor": 1,
  "rooms": 8,
  "slots": "7/7",
  "victory": true,
  "gold": 170,
  "build_points": 14,
  "events": 41
}
```

- 7 个内容槽位全部清空：战斗×2、事件、休整、精英、商店、Boss；
- Boss 使用房间规则能力（`boss_heat` 注入热量，自身热抗性）；
- 至少 3 种房间类型参与构筑；
- 两层配置下，首层 Boss 后触发 `floor_advanced`，第二层通关后结算。

## 未覆盖 / 已知偏差

- 玩家可玩 GUI 运行层在 M5-4 完成（`presentation/run_mode/run_mode.tscn`）；M4 阶段仅脚本驱动。
- 自动辅助方法 `auto_build_adjacent` / `auto_walk_into` / `CombatController.auto_resolve` 仅用于验收，不参与正式规则。
- 人工手感/可读性验收需真实窗口试玩（见 `docs/08`）。
