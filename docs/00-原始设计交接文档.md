# 1. 项目概述

## 1.1 游戏概念

《折叠地牢》是一款以空间构筑为核心的 Roguelike 游戏。

在传统地牢游戏中，玩家进入一个已经生成好的地牢，在其中探索、战斗、收集装备并逐渐变强。

而在《折叠地牢》中，玩家不仅需要探索地牢，还能主动改变地牢的结构。

玩家在探索过程中获得不同类型的房间，将它们放置、旋转、连接到自己的地牢布局中。每个房间都有独特的空间规则，这些规则不仅影响房间内部的战斗，也会与相邻房间产生交互。

例如：

- 熔炉房可以持续产生热量。
- 毒雾房可以向相邻房间扩散毒气。
- 镜面房可以反射投射物。
- 重力房可以改变物体的移动方向。
- 回声房可以重复某些行动。
- 蓄能房可以储存其他房间产生的能量。

当这些房间被组合起来时，会形成更复杂的系统。

例如：

**熔炉房 + 毒雾房 + 镜面房**

熔炉产生热量，毒雾遇热后产生爆燃，镜面房改变火焰传播方向。

玩家可以通过调整房间的位置和连接关系，主动制造战术优势。

游戏的主要乐趣不只是获得更强的武器，而是发现新的房间组合，理解规则之间的关系，并利用自己构筑的地牢击败越来越强的敌人。

## 1.2 核心设计理念

游戏需要坚持以下五个原则：

1. **空间本身就是构筑系统。** 房间不是单纯的地图内容，而是具有规则和功能的游戏组件。
2. **房间之间必须产生真实交互。** 不能只是把不同房间的数值加在一起，要让房间之间存在可观察、可利用的规则联动。
3. **玩家必须拥有主动规划能力。** 不能完全依赖随机生成，玩家需要通过选择、旋转、替换和重排来影响结果。
4. **战斗必须与空间构筑深度结合。** 房间布局不仅影响探索路线，还应该改变战斗策略。
5. **随机性必须服务于策略。** 随机提供不同的构筑机会，但不能让玩家感觉自己只能听天由命。

## 1.3 游戏的核心卖点

可以用一句话概括：

**别人进入地牢寻找宝藏，你建造地牢，让地牢成为自己的武器。**

玩家最终需要掌握的不是某一套固定的强力装备，而是如何理解和利用空间规则。

# 2. 游戏整体结构

## 2.1 游戏类型

采用以下设计组合：

- Roguelike：每局重新开始，地图、房间奖励、敌人和事件具有随机性。
- Tactical Turn-based Combat：战斗采用回合制战术系统。
- Spatial Building：玩家可以主动构筑地牢。
- Synergy System：房间之间可以形成组合效果。
- Run-based Progression：每局有明确的成长与终局目标。
- Meta Progression：局外可以逐步解锁新房间、新规则和新初始能力。

注意：游戏不是传统意义上的城市建设游戏，也不是以自由建造为主的沙盒游戏。

建造行为需要受到资源、位置、房间数量和关卡目标的约束。玩家必须在探索与构筑之间作出取舍。

## 2.2 视角与表现形式

第一版采用：

- 2D 俯视角。
- 像素风或精致的 2D 手绘风格，最终视觉方向需要在原型阶段确认。
- 房间以固定网格布局。
- 玩家在房间内部进行网格移动。
- 战斗使用回合制。
- 房间切换时通过门和连接关系进入相邻房间。

不需要第一版就制作复杂的 3D 地牢。

视觉重点应该放在：
- 房间结构清晰。
- 房间之间的连接关系容易理解。
- 环境效果能够明显表现规则变化。
- 房间联动时具有足够的动画和反馈。

# 3. 核心游戏循环

## 3.1 单局流程

一局游戏由多个地牢区域组成。

建议首版设计为：

1. 选择初始角色与初始房间。
2. 进入地牢起始区域。
3. 探索房间、击败敌人、发现资源。
4. 获得新的房间蓝图。
5. 在允许构筑的节点选择、放置或替换房间。
6. 逐步形成自己的地牢布局。
7. 发现并利用房间之间的规则联动。
8. 通过特殊房间获得强化或修复。
9. 挑战区域 Boss。
10. 进入下一层，面对更复杂的地牢规则。
11. 最终挑战地牢核心。
12. 胜利或死亡，结算本局奖励。

建议初期一局时长目标为 30–45 分钟，但这只是设计目标，需要通过试玩调整。

## 3.2 单个区域的流程

每个区域由以下内容组成：

| 内容 | 作用 |
|---|---|
| 起始房间 | 玩家进入区域的位置 |
| 普通房间 | 探索、战斗、资源收集 |
| 精英房间 | 更高风险、更好奖励 |
| 事件房间 | 特殊选择与规则变化 |
| 休整房间 | 恢复、调整布局 |
| 商店房间 | 购买房间、资源和强化 |
| Boss 房间 | 区域最终挑战 |

建议首个可玩版本每层包含 8–12 个已构筑房间。

其中玩家不是必须访问全部房间，而是需要根据资源和风险规划路径。

# 4. 地牢空间构筑系统

这是游戏最重要的系统。

## 4.1 基础地图结构

采用二维网格地图。

建议首版使用 5×5 的逻辑房间网格。

每个网格单元可以放置一个房间，也可以保持为空。

每个房间有固定的标准尺寸，例如 9×7 个地面 Tile。

示意：

```text
[空] [熔炉] [毒雾] [空] [空]
[空] [战斗] [镜面] [蓄能] [空]
[空] [入口] [走廊] [重力] [空]
[空] [空]   [休整] [空]   [空]
[空] [空]   [空]   [空]   [空]
```

上面的布局仅用于说明空间关系，不是最终地图设计。

每个房间具有：
- 房间类型。
- 房间尺寸。
- 房间入口与出口。
- 房间内部地图。
- 房间基础规则。
- 邻接交互规则。
- 战斗效果。
- 资源产出。
- 特殊限制。

## 4.2 房间连接规则

房间之间通过门连接。

第一版采用上下左右四方向连接。

房间可以有：
- 北门。
- 南门。
- 西门。
- 东门。

房间放置时需要满足连接约束：

1. 新房间必须至少有一个门与现有地牢连接。
2. 两个相邻房间的连接方向必须匹配。
3. 不允许门连接到不可通行的边界。
4. 不能覆盖已经存在的房间。
5. 不能超出地图范围。
6. 不能让已经构建的必经路径失效。

房间旋转时，门的位置和方向必须同步旋转。

例如，一个只有北门和东门的房间旋转 90 度后，门的位置也应该发生相应变化。

房间旋转是重要的构筑操作，不能只是视觉上的旋转。

## 4.3 房间放置与替换

玩家可以通过以下方式获得新房间：

- 探索奖励。
- 战斗奖励。
- 特殊事件。
- 商店购买。
- Boss 奖励。

获得房间后，玩家可以在指定构筑节点进行放置或替换。

初期不要允许玩家在任何战斗中随意修改整个地图。

建议限制为：

- 普通探索阶段：只能在构筑节点操作。
- 战斗阶段：不能改变房间位置。
- 特殊事件：可以获得一次临时重排机会。
- 休整房间：允许替换一个房间或旋转部分房间。

这样既能保留构筑自由，也能形成资源与时机管理。

## 4.4 房间的三个作用层次

房间不应该只有一种效果。

每个房间需要考虑三个作用层次：

**第一层：局部效果**

影响房间内部的探索和战斗。

例如：
- 熔炉房：每两回合产生一次热浪。
- 毒雾房：每回合对处于毒雾区域的单位造成伤害。
- 镜面房：特定方向的投射物会被反射。
- 重力房：单位移动和击退方向发生改变。

**第二层：邻接效果**

影响相邻房间。

例如：
- 熔炉房向相邻房间传递热量。
- 毒雾房向相邻且存在连通门的房间传播毒雾。
- 蓄能房储存相邻房间产生的能量。
- 冷冻房降低相邻熔炉房的热量。

**第三层：组合效果**

两个或多个房间满足条件时，触发新的特殊效果。

例如：

熔炉房 + 毒雾房：

```text
熔炉产生热量
    ↓
热量进入毒雾房
    ↓
毒雾达到高温阈值
    ↓
产生爆燃
    ↓
对房间内敌人造成范围伤害
```

镜面房 + 爆燃效果：

```text
爆燃产生火焰冲击
    ↓
镜面规则改变传播方向
    ↓
火焰沿指定方向传播
    ↓
可能攻击到多个敌人
```

这类组合应该成为游戏最重要的奖励体验。

需要注意：不能把所有房间组合都写成硬编码的独立效果。应当建立可复用的规则系统。

# 5. 房间设计与初始内容

## 5.1 房间分类

第一版建议将房间划分为六类：

| 类型 | 主要功能 |
|---|---|
| 元素房 | 产生热量、寒冷、毒雾等环境效果 |
| 转换房 | 改变其他房间产生的效果 |
| 传输房 | 传递能量、元素和投射物 |
| 战斗房 | 产生敌人或提供战斗优势 |
| 资源房 | 提供金币、材料、恢复和强化 |
| 特殊房 | 改变规则、提供特殊能力或事件 |

## 5.2 首批房间清单

首个原型不需要制作大量房间。

建议先制作以下 12 种。

### 元素房

**1. 熔炉房**

- 每回合积累热量。
- 热量达到阈值后产生热浪。
- 向相邻房间传递部分热量。
- 可以与毒雾、冰霜、蓄能等房间互动。

**2. 毒雾房**

- 产生毒雾。
- 毒雾可以沿开放连接扩散。
- 敌人和玩家进入毒雾区域会受到影响。
- 可以被高温、冷冻等效果改变。

**3. 冰霜房**

- 降低房间内温度。
- 对部分敌人施加减速。
- 可以冻结水面、毒雾或其他特殊地形。
- 可以限制火焰传播。

**4. 风暴房**

- 周期性产生风力。
- 改变投射物移动方向。
- 可以将气体和元素效果吹向相邻区域。

- 可以改变部分元素传播方向。
- 某些特殊攻击经过镜面时产生额外效果。
